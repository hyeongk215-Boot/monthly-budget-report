# 예산관리 (중국법인 월별 예산 대비 실적)

본사 회계담당자가 법인별/월별 손익(PL) 계정과목 기준으로 예산을 수립하고, 지점 담당자와
본사가 예산 대비 실적을 조회할 수 있도록 만든 웹 도구입니다. 관리부 ERP 통합시스템의 두 번째
데이터 모듈로, 회계관리 → **예산관리** → 자금집행 → 실적분석 파이프라인의 일부입니다.
한국어/中文 2개 언어를 지원합니다.

회계관리, 접대비 앱과 동일하게 바닐라 HTML/JS/CSS + Supabase + GitHub Pages 구조입니다. Supabase
프로젝트는 회계관리와 **같은 관리부 ERP 전용 프로젝트를 공유**합니다 (접대비는 별도 프로젝트).

## 회계관리와의 차이점
- **방향이 반대**: 회계관리는 "지점 제출 → 본사 집계"지만, 예산관리는 "본사 수립 → 지점 조회"입니다.
  지점 담당자는 자기 법인의 예산/실적을 볼 수만 있고 수정할 수 없습니다.
- **실적을 별도 저장하지 않음**: 실적(실제 금액)은 회계관리의 `acct_statement_lines`
  (statement_type='PL')를 그때그때 조인해서 가져옵니다. 같은 Supabase 프로젝트를 쓰기 때문에
  가능한 설계이며, 회계관리 데이터가 갱신되면 예산관리도 별도 동기화 없이 항상 최신 실적을 보여줍니다.
- **계정과목을 재정의하지 않음**: 회계관리의 `acct_accounts`(PL만)를 그대로 씁니다.

## 구성
- `docs/` — GitHub Pages로 배포되는 프론트엔드
  - `index.html` — 법인/적용년도월/접근키 입력 (조회 전용이라 담당자 이름 입력 없음)
  - `view.html` — 선택한 법인의 계정별 예산/실적/달성률을 읽기 전용으로 표시, 초과 시 배지/행 색상
  - `admin.html` — [본사용] 접근키로 로그인 후 법인/월별 예산 입력·저장, 월 마감, 전체 법인 통합 리포트 조회/엑셀 다운로드
- `supabase/` — 테이블/함수 정의 (`schema.sql`). **회계관리의 schema.sql이 먼저 적용되어 있어야** 정상 동작합니다 (자세한 내용은 `supabase/README-deploy.md` 참고).

## 배포 방법
`supabase/README-deploy.md`를 따라 Supabase에 스키마를 적용한 뒤,
`docs/js/config.js`의 `SUPABASE_URL`/`SUPABASE_ANON_KEY`를 채우고 GitHub Pages로 배포하세요.

## 로컬 실행
```
python -m http.server 8091 --directory docs
```

## 접근키
회계관리와 같은 `access_keys` 테이블을 씁니다. `finance`/`system_admin` 키는 예산 수립 권한도
가지며, `branch_<slug>` 키는 자기 법인의 예산/실적을 조회만 할 수 있습니다.

## 커스터마이징
- 법인 목록: `docs/js/config.js`
- 다국어 문구: `docs/js/i18n.js`
- 계정과목: 이 모듈에서 관리하지 않으며, 회계관리의 admin.html에서 변경하면 즉시 반영됩니다.
