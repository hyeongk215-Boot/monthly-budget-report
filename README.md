# 예산관리 (중국법인 월별 예산 대비 실적)

본사 회계담당자가 법인별/월별 손익(PL) 계정과목 기준으로 예산을 수립하고, 지점 담당자와
본사가 예산 대비 실적을 조회할 수 있도록 만든 웹 도구입니다. 관리부 ERP 통합시스템의 두 번째
데이터 모듈로, 회계관리 → **예산관리** → 자금집행 → 실적분석 파이프라인의 일부입니다.
한국어/中文 2개 언어를 지원합니다.

회계관리, 접대비 앱과 동일하게 바닐라 HTML/JS/CSS + Supabase + GitHub Pages 구조입니다. Supabase
프로젝트는 회계관리와 **같은 관리부 ERP 전용 프로젝트를 공유**합니다 (접대비는 별도 프로젝트).

## 회계관리와의 차이점
- **방향이 반대**: 회계관리는 "지점 제출 → 본사 집계"지만, 예산관리는 "본사 수립 → 지점 조회"입니다.
  지점 담당자는 자기 법인의 예산/실적을 볼 수만 있고 수정할 수 없습니다.
- **실적을 별도 저장하지 않음**: 실적(실제 금액)은 회계관리의 `acct_statement_lines`
  (statement_type='PL')를 그때그때 조인해서 가져옵니다. 같은 Supabase 프로젝트를 쓰기 때문에
  가능한 설계이며, 회계관리 데이터가 갱신되면 예산관리도 별도 동기화 없이 항상 최신 실적을 보여줍니다.
- **계정과목을 재정의하지 않음**: 회계관리의 `acct_accounts`(PL만)를 그대로 씁니다.

## v3 업데이트 (연간 제출 방식으로 전환)
계정과목별 예산 + 목표영업이익 입력 방식이 "본사가 매월 설정"에서 "지점이 연 1회(1~12월 한 번에)
제출"로 바뀌었습니다.
- `view.html`이 연간 입력 화면으로 교체되었습니다: 지점이 계정과목별 예산 12개월치와 목표영업이익
  12개월치를 한 화면에서 입력해 제출합니다 (`bgt_budget_lines`에 office 차원 추가).
- 제출하면 해당 법인×지점×연도가 자동 잠깁니다 (`bgt_annual_lock`). 이후 수정은 system_admin/
  finance만 admin.html에서 잠금 해제 → 재제출하는 방식으로 가능합니다.
- `ga-submit.html`(일반관리비 입력)이 로그인 후 기본 페이지가 되었고, 하단에 당해 누계 목표영업이익
  달성 상황(1~12월 목표 vs 실적)을 보여줍니다.
- admin.html의 옛 "이 달 예산 상태"/"목표영업이익 설정" 카드는 제거되고, 연도별 법인×지점 목표
  달성 현황 리포트(진행률 표기, 엑셀 다운로드, 잠금 해제 버튼)로 교체되었습니다.

## v2 업데이트 (목표영업이익 + 일반관리비 세부 예산/실적)
- **목표영업이익(한국식)**: 법인 산하 지점별 월간 목표영업이익을 admin.html에서 본사가 입력합니다
  (`bgt_target_profit`). 실적분석의 목표실적 관리표가 회계관리 PL(한국)의 영업이익 실적과 비교해
  달성률을 계산하는 데 씁니다.
- **일반관리비 세부 예산/실적**: 기존 계정과목 단위 예산과 별개로, 11개 비용항목(인건비/복리후생비/
  접대비/출장비/감가상각비/임차료/사무실운영비/차량유지비/자문및감사비/시스템유지비/은행수수료)을
  고정비/변동비로 나눠 **지점이 직접 예산과 실적을 함께 입력**하는 신규 그리드입니다
  (`bgt_ga_lines`). `ga-submit.html`에서 지점이 입력하고, admin.html에서 본사가 전체 법인·지점
  취합본을 조회/엑셀 다운로드합니다. 이 방향은 기존 계정과목 예산(본사 수립 → 지점 조회)과 반대로,
  회계관리의 제출 패턴(지점 제출 → 본사 집계)을 따릅니다.

## 구성
- `docs/` — GitHub Pages로 배포되는 프론트엔드
  - `index.html` — 법인/지점/적용년도월/담당자/접근키 입력
  - `view.html` — 선택한 법인의 계정별 예산/실적/달성률을 읽기 전용으로 표시, 초과 시 배지/행 색상.
    "일반관리비 입력" 링크로 `ga-submit.html` 이동
  - `ga-submit.html` — 지점 담당자가 일반관리비 11개 항목의 예산/실적(고정비/변동비)을 입력·제출
  - `admin.html` — [본사용] 접근키로 로그인 후 법인/월별 예산 입력·저장, 목표영업이익 설정,
    일반관리비 취합 조회/다운로드, 월 마감, 전체 법인 통합 리포트 조회/엑셀 다운로드
- `supabase/` — 테이블/함수 정의 (`schema.sql`). **회계관리의 schema.sql이 먼저 적용되어 있어야** 정상 동작합니다 (자세한 내용은 `supabase/README-deploy.md` 참고).

## 배포 방법
`supabase/README-deploy.md`를 따라 Supabase에 스키마를 적용한 뒤,
`docs/js/config.js`의 `SUPABASE_URL`/`SUPABASE_ANON_KEY`를 채우고 GitHub Pages로 배포하세요.

## 로컬 실행
```
python -m http.server 8091 --directory docs
```

## 접근키
회계관리와 같은 `access_keys` 테이블을 씁니다. `finance`/`system_admin` 키는 예산 수립 권한도
가지며, `branch_<slug>` 키는 자기 법인의 예산/실적을 조회만 할 수 있습니다.

## 커스터마이징
- 법인 목록: `docs/js/config.js`
- 다국어 문구: `docs/js/i18n.js`
- 계정과목: 이 모듈에서 관리하지 않으며, 회계관리의 admin.html에서 변경하면 즉시 반영됩니다.
